BoxOffice Brain · ClickHouse-grounded

Ask the warehouse. Get the numbers, or an honest "I can't."

A cinema-catalogue analytics agent that writes read-only ClickHouse SQL, runs it through ClickHouse's own MCP server, shows the exact query and what it scanned, and grounds every claim in rows it actually retrieved. When the data can't answer, it abstains instead of guessing.

What am I looking at?

  • Live mode means this page is talking to boxoffice serve: pressing Ask runs the real Python pipeline and every panel below is filled from that run's return value.
  • Recorded mode means the page was opened as a file with no backend. It then replays a transcript that scripts/record_transcript.py captured from a real run, and says so in the banner. Nothing here is hand-written output.
  • Agent activity log lists the run's events and the guardrail audit trail the state store recorded: read-only screen, data-scope allowlist, and the action limiter.
  • Grounding trace is the evidence: the exact SQL, rows read, bytes scanned, latency, and which transport served it.
  • Abstain is a feature: when the retrieved rows can't support the question, or the query failed, the agent says so instead of inventing a number.
